# Alice Zhao — Portfolio

Static site, two files:

- `index.html` — the whole portfolio (home + all case studies)
- `2077ai-datasets.html` — the live 2077 AI Datasets page, embedded in its case study and home card

Deploy: upload both files plus `.nojekyll` to the repo root, then Settings → Pages → Deploy from a branch → main / root. Keep the two HTML files in the same folder.

- `vitiligo-app.html` — the live Vitiligo prototype embedded in the Vitiligo AI case study. Keep it next to `index.html`.
